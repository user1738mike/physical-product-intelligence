# ADR 0002: Tenant isolation before ingestion
Status: implemented for Phase 2 identity/organization/membership/audit resources. Decision: global users, current organization memberships and mandatory tenant context; deny-by-default services and organization-scoped nested lookups. Do not rely on UUID obscurity. ADR 0006 defines exact roles, ownership and session policy. Consequences: adversarial tests gate every future resource. RLS is deferred until transaction/pooling context and bypass rules can be tested; application scoping remains mandatory.
