## B. Implementation and decisions

One existing Docker architecture is retained: strict production application base plus an isolated local rehearsal overlay with CA-verified nginx HTTPS, PostgreSQL 17 TLS, separate migration and runtime roles, persistent private/backup/restore/TLS/signature volumes and real ClamAV. No internal application/DB/scanner host ports are exposed. A read-only/non-root application and resource-bounded single host remain the supported topology; no new worker/queue or hosting provider is invented.

Significant changes: `compose.production.yaml`, `compose.rehearsal.yaml`, `deploy/bootstrap-tls.sh`, `deploy/nginx.conf`, backend/frontend Dockerfiles, `scripts/release.py`, `release_preflight.py`, `release_probes.py`, `release_security.py`, `build_previous.py`, recorded smoke helper and deployment documentation. Backend adds guarded migration ownership, synthetic runtime-role/access checks, explicit rehearsal-only recorded extraction, required-scanner readiness and no-store middleware around early CSRF/Host denials. Gunicorn's default control socket is disabled for its read-only filesystem. CI adds image/dependency security gates and patched Python/Node versions while retaining locked application dependencies.

The release controller validates isolated project/DB identities, uses an exclusive host lock and a PostgreSQL migration advisory lock, quiesces only rehearsal writers, preserves data, records each result and refreshes ingress after application replacement. Rollback changes application only, with no reverse migration. Prior code is exported from Git without checkout/reset and receives the same runtime security patches; it is explicitly a derivative prior-code image, not an original historical binary.

`config.settings.rehearsal` requires both a synthetic-only marker and a generated rehearsal DB name. Its recorded provider has no network/credential/SDK path; production cannot enable it by provider name alone. Human approval/canonical selection remains explicit. The deterministic rules engine is unchanged.
